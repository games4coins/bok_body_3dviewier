# BOK Body · 3D-просмотрщик

Статический веб-просмотрщик STL (ASCII и бинарный) и OBJ. Для OBJ отображается геометрия поверхностей с материалом просмотрщика. MTL и текстуры не подключаются. Файлы моделей читаются браузером и остаются на устройстве.

На ПК для вращения перетаскивайте модель мышью. На телефоне используйте один палец. Зум работает колёсиком, жестом двумя пальцами или кнопками + и −. Кнопка «Вписать» возвращает исходный ракурс. Справа можно выбрать схему света и изменить яркость и угол. На телефоне настройки находятся под моделью.

## Локальный запуск

В каталоге проекта выполните `python -m http.server 8000` (на Windows также работает `py -m http.server 8000`). Откройте <http://localhost:8000>. Нужен современный браузер с WebGL 2 и подключение к CDN jsDelivr для загрузки Three.js.

## Публикация

Загрузите содержимое каталога в корень репозитория `bok_body_3dviewier`. В GitHub выберите **Settings → Pages → Deploy from a branch**, затем ветку `main`, папку `/(root)` и нажмите **Save**. Статус публикации появится в разделе Pages.
